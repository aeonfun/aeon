## Telegram 输出格式

- Telegram 的 Markdown **不支持表格**，写 `| a | b |` 和 `|---|` 会原样显示。
- 需要并排对比的数据（价格/流动性/涨跌这类），**用 ``` 代码块包裹**，等宽字体能对齐。
- 只有 2-4 项、不需要对比时，用竖排列表：`• 标签: 值`。
- 粗体 `**这样**` 有效，可以用。
- 每个数字后面带上来源和口径（哪个 API、什么时间），方便我判断新鲜度。
